# Technology Stack

## Frontend

- React.js
- Tailwind CSS
- Chart.js
- Framer Motion

The frontend is responsible for providing the interactive user interface, dashboards, charts, and visual presentation of predictions and insights.

## Backend

- FastAPI

FastAPI is used as the backend framework for handling application APIs and communication between the frontend and intelligence components.

## Machine Learning

- Scikit-learn
- XGBoost
- LightGBM
- TensorFlow
- SHAP

These technologies support machine learning, prediction, model development, and explainable AI capabilities.

## AI Layer

- OpenAI
- LangChain

The AI layer supports intelligent processing, knowledge retrieval, and AI-powered decision support.

## Database

- PostgreSQL
- SQLite

The project architecture includes database storage for application and data management.

## Deployment

- Frontend: Vercel
- Backend: Railway & Render
- Database: Neon PostgreSQL
- Model Files: Backend Storage
